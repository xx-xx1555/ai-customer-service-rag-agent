RAG 是检索增强生成技术。它的核心思想是先从知识库中找到和用户问题相关的内容，再把这些内容交给大模型生成答案。

RAG 系统一般包含文档上传、文本解析、Chunk 切分、向量化、向量检索、Prompt 拼接、大模型生成和来源追踪几个步骤。

Embedding 是把文本转换成向量的过程。向量可以用于计算文本之间的相似度。知识库问答系统会把用户问题和文档片段转换到同一向量空间中，然后检索最相关的片段。

混合检索是指同时使用向量检索和关键词检索。向量检索更适合理解语义相似，关键词检索更适合命中精确词。Rerank 会对召回结果进行二次排序，让最终交给大模型的上下文更准确。

Agent 不是普通聊天机器人。Agent 通常包含意图识别、工具选择、工具调用和结果汇总。比如用户问知识库问题时调用 RAG 工具，用户问工单统计时调用工单分析工具。

FastAPI 是一个常用的 Python Web 后端框架。它可以通过 Pydantic 定义请求和响应模型，并自动生成 Swagger 接口文档。
